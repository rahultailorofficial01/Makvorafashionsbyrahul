# 👑 MAKVORA PARIS — Ultra-Luxury Bespoke Tailoring & Haute Couture Website

Welcome to **MAKVORA**, a high-end luxury bespoke tailoring and fashion website built for a global haute couture maison.

---

## 🌟 Key Features & Highlights

- 🎥 **Cinematic Hero Section**: Fullscreen background video showing slow-motion tailoring craftsmanship with dark overlay and founder attribution (*Master Tailor Suresh Tailor & Rahul*).
- 🪡 **The Art of Bespoke (Interactive Stepper)**: 4-Stage craftsmanship timeline (*Anatomical Measurement, Pattern Blueprinting, Floating Canvas Basting, Final Hand-Stitching*) connected with an animated Framer Motion progress line.
- 🧵 **Exclusive Textile Library & Swatches**: High-contrast interactive swatches for *Wild Peruvian Vicuña*, *24k Gold Thread Silk*, *Obsidian Cotton Velvet*, and *Royal Banarasi Silk*.
- 🧥 **Royal Safari Suits Collection & Overview**:
  - Full-page slide preview showcasing Bandhgala, Linen Belted, Royal Gray, and Military Safari Suits.
  - Interactive slide selector / model thumbnails.
  - Sizing chart & luxury fabric specifications.
- 🎨 **"Design It Your Way" Safari Customizer**: 3D/Style builder allowing customization of 4 lapel styles, 8 pocket configurations, waist belts, sizes, colors, and personalized initial monograms (`MKV`).
- 💰 **Dual Currency Switcher**: Real-time price valuation toggle between **INR (₹)**, **USD ($)**, and **EUR (€)**.
- 🛒 **Private Selection Cart Drawer**: Slide-over cart drawer with quantity adjustments and valuation totals.
- 💳 **Full-Page Secure Checkout Experience**: Multi-protocol payment options (*Black Card, Swiss Wire, UPI, Crypto Vault*), client delivery form, and instant order confirmation with downloadable invoice PDF receipt.
- ❓ **Interactive Accordion FAQ**: Client concierge accordion covering fitting turnaround times and worldwide residence visits.

## 🛠️ Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router architecture with React 19)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
  - Palette: Off-White Cream (`#FDFBF7`), Dark Espresso Noir (`#050505`), Soft Gold (`#D4AF37`)
  - Fonts: Playfair Display (Serif Headings) & Poppins/Inter (Body Copy)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Iconography**: [Lucide React](https://lucide.dev/)
- **Asset Optimization**: Next.js `next/image`

## 🚀 Local Development Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/rahultailorofficial01/Makvorafashionsbyrahul.git
   cd makvora-website
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Open in Browser**:
   Navigate to [http://localhost:3000](http://localhost:3000)
